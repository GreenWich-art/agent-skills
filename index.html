什么是 Agent Skill？

Agent Skill 是一个装着「操作手册 + 脚本 + 资源」的文件夹（核心是其中的 SKILL.md）。AI Agent 读到对应任务时，会按手册里的流程和脚本自动完成——把一套反复要用的工作流固化一次，长期复用。

本合集遵循开放的 Agent Skills 规范，不绑定单一产品。

适合谁

在电脑上使用 AI Agent 的开发者与研究者：WorkBuddy、Claude Code、Codex、Cursor 等宿主的用户，需要本地 OCR、论文排版、文献检索下载、桌面自动化等具体能力的人。技能需安装到本地 skills 目录使用，因此目标用户是桌面端；不适合完全不用 AI Agent 的用户。

怎么安装

方式一：npx skills CLI（推荐）——自动识别 69+ 种 Agent 宿主，一条命令装单个技能：

# 装单个技能（以 OCR 为例，换成其他名字即可）
npx skills add GreenWich-art/skill-macos-vision-ocr

# 装到用户级目录（跨项目可用）
npx skills add GreenWich-art/skill-macos-vision-ocr -g

方式二：下载 zip 手动安装——打开上面任一技能的「下载 zip」（或各子库 Releases 页面），解压后把技能文件夹放进宿主的 skills 目录：

宿主用户级目录（所有项目可用）
WorkBuddy~/.workbuddy/skills/
Claude Code~/.claude/skills/
Codex~/.codex/skills/

注意：解压后应是 skills/<技能名>/SKILL.md 这一层，不要多套目录。公开仓库的 zip 无需登录即可下载。

方式三：Claude Code 插件市场：

/plugin marketplace add GreenWich-art/agent-skills

然后在 Claude Code 里按名字安装单个技能插件。

常见问题

下载 zip 需要登录 GitHub 吗？
不需要。仓库和 Release 资产均为公开，直接下载。
装完怎么用？
直接对 Agent 描述任务即可，技能会按 SKILL.md 里的触发词自动激活；也可以显式点名，如「用 macos-vision-ocr 识别这张图」。
支持 Windows / Linux 吗？
除 macos-vision-ocr（依赖 macOS 系统框架）和 desktop-takeover（仅验证 macOS）外，其余技能跨平台可用；各自的 README 里有说明。
收费吗？可以商用吗？
MIT License，免费使用、可修改、可商用，保留作者署名即可。
